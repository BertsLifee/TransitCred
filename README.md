# Telegram Group Mini App

Welcome to our Telegram Mini App! This interactive web app is built using HTML, Tailwind CSS, and the Telegram Web Apps SDK.

## Features
- **Telegram SDK Integration**: Automatically detects user context within Telegram chats.
- **Interactive Actions**: Custom actions that send data directly back to the group bot.
- **Responsive UI**: Styled using Tailwind CSS to automatically adapt to Telegram's dark/light themes.

## Setup & Deployment
1. Hosted via GitHub Pages.
2. Linked to Telegram Bot via `@BotFather` using `/newapp`.
3. Added to the group menu button for easy access.
